# Brand assets

`google-g.svg` is the original Google artwork from https://www.gstatic.com/firebasejs/ui/2.0.0/images/auth/google.svg.
`google-g.png` is a 96px rasterization of that SVG for Flutter, preserving the original shape and colours.
The shared JustRide logo is `assets/justride-logo-horizontal.png`.
